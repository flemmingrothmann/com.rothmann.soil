# GPD Button Cheat Sheet

## Lightbee Flemmings Vaerelse

The button uses a `CR2430` battery. The Sonoff dongle is currently the GPD translator in this installation. Planned Nordtronic rotary dimmers will later provide GPD translation and take over this temporary role.

Zigbee channel: `20`.

### Recommission / Pair Again

1. Hold the **bottom-left button** for at least `7 seconds`.
2. Press the **bottom-left and top-right buttons simultaneously** to confirm channel `20`.
3. Do not press another button between the two steps.
4. Test the button with a normal short press.

### Button Layout

```text
top-left       top-right
bottom-left    bottom-right
```

For this installation, the pairing sequence is:

```text
bottom-left (at least 7 seconds)
bottom-left + top-right (simultaneously)
```
